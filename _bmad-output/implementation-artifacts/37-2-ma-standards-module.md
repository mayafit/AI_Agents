## Story

As a **developer on a BMAD v7 project**,
I want the organisation's standards — language, quality, git, documentation and training skills — installable as one module (`npx skills add … --skill bmod-ma-standards --skill <each member>`, then `bmad setup ma-standards`), each skill activating through `render_skill.py` like an upstream skill, and `ma-standards-apply` writing the list of installed standards into my coding tool's instruction files between its own markers,
so that every agent session sees which standard to activate for which work, and the block never collides with the installer's `ma-agents` block or upstream's `bmad:context` block.

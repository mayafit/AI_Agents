## Story

As the **ma-agents maintainer**,
I want the public repository `github:mayafit/ma-bmad-extensions` laid out as BMAD v7 modules — the four `bmod-<code>/` records, one placeholder member per module, and a CI that runs upstream `validate_manifests.py`, the 36.4 contract validator, the skill-guidance lint, the module-assignment and `bmad-*` name tests and a per-module install test against the pinned BMAD commit —
so that 37.2–37.4 fill each module into a layout whose every gate already runs, and a module that does not install alone, or a skill in the wrong module, fails CI on the commit that introduces it.

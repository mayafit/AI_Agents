What the 3.x line is evidence of: ma-agents 3.x never called the Jira REST API itself. `lib/store-backends.js` enumerates `file-system` and `confluence` only (`:41`); the one 3.x Jira skill, `my-next-issue`, handed the JQL `project = {jira_project_key} AND assignee = currentUser() AND statusCategory != Done ORDER BY priority DESC, rank ASC` to "whatever Jira-capable tool is available in your current tool context" (`SKILL.md:27-35`) and stopped on a shared account (`:44`). So 3.x contributes the JQL and the identity rule; the endpoint forms are checked against the documentation (D1).
